    An app that sees your keyboard has to earn your trust. So every promise comes with a way to check it.

    It never goes online

    There is no networking code in the app. Search the source for HttpClient or Socket, or block it in your firewall and watch it keep working.

    It never saves what you type

    Typed text only lives in memory while the popup is open. The only file it writes holds your settings and a count of which emojis you picked.

    Questions

    Windows says it protected my PC. Is it safe?

    That message shows for apps that are new and not yet signed with a paid certificate. Click "More info", then "Run anyway". The full source is public, and each download is built by GitHub from that source.

    Why does it need to see my keyboard?

    To notice when you type a colon. That is the whole trick. It ignores everything else and never stores or sends it.

    Does it work in games?

    Yes, it is built to work in game chats that take normal typing. In windowed or borderless mode the popup shows over the game. In exclusive fullscreen Windows does not let any app draw on top, so type the full code like :skull: and it converts without the popup. If a game ignores the emoji, turn on paste mode for it in the tray panel. Whether the emoji shows up depends on the game's font. We have not tested specific games yet, so tell us how it goes.

    What about apps running as administrator?

    Windows does not let normal apps read keys typed into admin windows, so it will not work there unless you also run it as administrator.

    Is it really free?

    Yes. No ads, no premium version, no account. It is open source under the MIT license.

    How do I remove it?

    Open Windows Settings, then Apps, find Emoji Anywhere and click Uninstall. It removes the app and its settings.
